Welcome

1. Introduction

FreshBox is a modern, commercial-grade HTML5 template designed for grocery delivery businesses, weekly/biweekly subscription services, organic food stores, fresh produce platforms, and grocery box startups.

Technology Stack:
  • HTML5 & CSS3: Modern semantic markup with SEO and accessibility metadata.
  • Bootstrap 5.3.3: Responsive flexbox & grid system.
  • Vanilla JavaScript (ES6+): Zero bulky framework dependencies (no React, Vue, Angular, or jQuery).
  • Bootstrap Icons: Vector icons that scale crisply.
  • Google Fonts: Outfit (Headings) & Plus Jakarta Sans (Body text).
  • LocalStorage State: Persists dark mode, RTL preferences, cart items, and mock demo auth roles.

3. Color & CSS Variables

To rebrand the entire website with your custom brand colors, simply edit the CSS custom properties in assets/css/style.css:

:root {
  /* Brand Colors */
  --primary: #2e7d32;           /* Primary Fresh Green */
  --primary-dark: #1b5e20;      /* Dark Green */
  --primary-light: #4caf50;     /* Leaf Green */
  --secondary: #8bc34a;         /* Lime Accent */
  --accent-orange: #ff9800;     /* Warm Harvest Orange */
  --body-bg: #f8faf9;           /* Clean Page Background */
  --card-bg: #ffffff;           /* Card Surface */
  --dark: #1a221e;              /* Dark Charcoal Text */
}

4. Dark Mode & RTL Layouts

Dark mode and RTL are seamlessly integrated via standalone helper scripts:

  • Dark Mode: Toggled by assets/js/theme.js. Sets data-bs-theme="dark" on the <html> element and persists choice in localStorage under freshbox_theme.
  • RTL Mode: Toggled by assets/js/rtl.js. Sets dir="rtl" and lang="ar" on the <html> element and persists in localStorage under freshbox_dir.

5. Box Builder & Cart State

The interactive box customizer (shop.html) and sample box (sample-box.html) communicate with assets/js/main.js through window.freshboxApp: 

// Add item to box
freshboxApp.addToCart({
  id: 'item-1',
  name: 'Fresh Vine Tomatoes',
  category: 'vegetables',
  price: 60,
  unit: '1 kg',
  image: 'path/to/image.jpg'
});

// Update Quantity (+1 or -1)
freshboxApp.updateQty('item-1', 1);

// Trigger Toast Alert
freshboxApp.showToast('Title', 'Message body text', 'success');

6. Dashboards & Authentication

The template includes dynamic navbar rendering based on authentication state:

  • Guest Role: Displays "Sign In" button linking to login.html.
  • Customer Role: Displays "Chandru" with profile avatar and subscriber links (My Dashboard, My Subscription, My Orders, Billing).

Login with your customer credentials on login.html to access the subscriber dashboard.
